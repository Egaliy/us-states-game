# Штаты США

Локальный тренажёр по 50 штатам. Дизайн-система взята из «Стран мира» (`~/Projects/countries-game`):
системный шрифт, светло-серый фон, белые карточки, один синий акцент, тёмная тема по системе.

## Сайт

Опубликовано на https://us-states-game-delta.vercel.app (проект Vercel `us-states-game`, тот же аккаунт, что у «Стран мира»).
Деплой: `npx vercel@latest --prod --yes` из папки проекта.

## Запуск

```bash
npm install
npm run dev
```

Открывается на http://127.0.0.1:5180. На рабочем столе есть ярлык «Штаты США.command», он делает то же самое.

## Режимы

**Вписать штаты.** Поле ввода, штат засчитывается сразу по мере набора, Enter не нужен. Принимаются русские
и английские названия. Нормализация прощает дефисы, пробелы, «э/е», «й/и» и удвоенные буквы, поэтому
«Нью Йорк», «Масачусетс», «Миссиссипи», «Делавер» тоже засчитываются. Угаданный штат заливается синим на карте,
в списке по регионам (Северо-Восток, Средний Запад, Юг, Запад) появляется силуэт и название.
«Округ Колумбия», «Пуэрто-Рико», «Гуам» не засчитываются: подсказка, что это не штат.
«Сдаться» срабатывает со второго нажатия. После финала пропущенные штаты красные на карте и в списке.

**Найти на карте.** Сверху липкая подсказка «Найдите на карте: Техас», три попытки (точки).
Неверный клик подсвечивает штат красным и пишет «Это Оклахома». Верный клик: зелёный, если с первого раза,
оранжевый со 2–3 попытки. После трёх промахов или «Пропустить» нужный штат мигает красным, пауза 1,2 с, дальше.
Рекорд: штаты с первого раза, при равенстве лучше меньшее время. Названия при наведении видны только
у уже отвеченных штатов, после финала у всех.

Мелкие штаты (Массачусетс, Род-Айленд, Коннектикут, Нью-Джерси, Делавэр, Мэриленд) дублируются плашками в океане
с выносками, по плашке можно кликать.

## Данные

`src/states.js` — 50 штатов: FIPS-код, русское и английское название, варианты, регион.
`src/map-data.js` — пути штатов, сгенерированы `npm run map` (скрипт `scripts/build-map.mjs`) из пакета `us-atlas`
(проекция Albers USA, Аляска и Гавайи врезками). Руками не править.
`scripts/check-names.mjs` проверяет словарь: нет коллизий и ранних срабатываний, когда одно название — начало другого.

Хранение в localStorage: партия `us-states-state-v1` (оба режима отдельно), рекорды `us-states-records-v1`.
