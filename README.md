# US States

**[Play →](https://us-states-game-delta.vercel.app)**

[![US States](preview.jpg)](https://us-states-game-delta.vercel.app)

A geography quiz: find all 50 US states on an interactive map.

**Stack:** Vite, vanilla JavaScript, d3-geo + TopoJSON (us-atlas).

```bash
npm install
npm run dev
```
